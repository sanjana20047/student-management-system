# Student Management System

## Project Description
This project is developed to manage student records efficiently using frontend, backend, and database technologies.

## Features
- Student Registration
- Login System
- Add Student Details
- Update Student Details
- Delete Student Records
- Search Student Information

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP/Java
- MySQL

## Folder Structure
frontend/
backend/
database/
screenshots/

## Installation Steps
1. Download the project
2. Import database.sql into MySQL
3. Start Apache and MySQL in XAMPP
4. Run the project in browser
